Ready to manage your server?

Discord sign-in is being prepared. Until it is ready, you can continue using CC’s existing private guild-panel link.

Keep your link private. It grants access to your guild panel. If it may have been shared, ask the bot owner to revoke the token and issue a new one.
  1. 01
    Open Discord

    Go to the server where CC is installed.

  2. 02
    Request your panel link

    Run /guildpanel token and follow the bot’s private message.

  3. 03
    Open your dashboard

    Use your guild-specific link to sign in and manage the features available to you.
